graficaBarra

Developer's reference for the GraficaBarraClass chart engine — thirteen chart types, how it works and how to drive it from code, on Clarion windows and reports.

Referencia del desarrollador para el motor de gráficos GraficaBarraClass — trece tipos de gráfico, cómo funciona y cómo usarlo desde código, en ventanas e informes de Clarion.

13 types · pure Clarion · BOX / LINE / POLYGON / ELLIPSE / PIE / SHOW · window + report · vector PDF

OverviewResumen

New in v2.1 — bars and a line on the one chart. A series can now be told its own shape, whatever ChartType says: Obj.SetSeriesPlot(2, Plot:Line) draws series 2 as a line over the bars of the others — sales as columns, the trend as a line, both off the same value axis. The line series takes no room in the category slot, so one bar series beside one line still draws full-width bars, and the legend keys it with a line rather than a block. Chart:Column, Chart:Line and Chart:Scatter only. A chart that never calls it is untouched.
And a tighter axis. The auto-scale now sizes the step between two gridlines and runs the axis to the first whole step past the data, instead of rounding the top up to the next 1/2/5 magnitude. A maximum of 113,376,143 used to get an axis of 200,000,000 — every bar at half height; it now gets 125,000,000. Scale divisions became a ceiling rather than an exact count, because every gridline has to land on a whole step.
And cells with no value. Obj.SetNoValue(series, category) says one series has nothing to say about one category: no bar, no marker, and the line breaks there instead of diving to zero. A row of periods with an average bar on the end is the case — the bar belongs on the chart, the trend does not run out to it.
And its own type. FontName, FontSize and FontStyle draw the chart's labels in a font of its own — SETFONT on the drawing target is the window's font, so the chart puts its type on, draws, and hands the target's own back before Paint returns. A FontSize also scales the layout, because nothing on the chart is measured from the real font.
Nuevo en v2.1 — barras y una línea en el mismo gráfico. Ahora se le puede decir a una serie su propia forma, diga lo que diga ChartType: Obj.SetSeriesPlot(2, Plot:Line) dibuja la serie 2 como una línea sobre las barras de las demás — las ventas en columnas, la tendencia en línea, las dos del mismo eje de valores. La serie de línea no ocupa lugar en la ranura de la categoría, así que una serie de barras al lado de una de línea sigue dibujando barras de ancho completo, y la leyenda la marca con una línea y no con un bloque. Solo Chart:Column, Chart:Line y Chart:Scatter. Un gráfico que nunca la llama queda igual.
Y un eje más ajustado. La escala automática ahora dimensiona el paso entre dos líneas de rejilla y lleva el eje hasta el primer paso entero que pasa los datos, en vez de redondear el techo a la siguiente magnitud 1/2/5. Un máximo de 113.376.143 recibía un eje de 200.000.000 — todas las barras a media altura; ahora recibe 125.000.000. Las divisiones de escala pasaron a ser un techo y no una cantidad exacta, porque cada línea tiene que caer en un paso entero.
Y celdas sin valor. Obj.SetNoValue(serie, categoría) dice que una serie no tiene nada que decir de una categoría: sin barra, sin marcador, y la línea se corta ahí en vez de caer a cero. Una fila de períodos con una barra de promedio al final es el caso — la barra va en el gráfico, la tendencia no llega hasta ella.
Y su propia tipografía. FontName, FontSize y FontStyle dibujan las etiquetas del gráfico con una fuente propia — SETFONT sobre el destino es la fuente de la ventana, así que el gráfico pone la suya, dibuja, y devuelve la del destino antes de que Paint termine. Un FontSize además escala la maquetación, porque nada del gráfico se mide de la fuente real.
New in v2.0 — thirteen chart types. One property, ChartType, switches between Chart:Column, Chart:Bar, Chart:StackedCol, Chart:StackedBar, Chart:Stacked100, Chart:Line, Chart:Area, Chart:StackedArea, Chart:Scatter, Chart:Pie, Chart:Pie3D, Chart:Donut and Chart:Radar. Up to 8 series (AddSeries + AddCat), a legend, markers, smooth (Catmull-Rom) lines, percentage labels, and a scale that puts zero on a gridline. Everything below still applies — the v1 API (AddBar, ClearBars, SetRange, Draw, Paint) is unchanged, and Chart:Column is the default, so v1 code draws exactly as it did.
Pie, 3D pie and donut are built on Clarion's own PIE statement, and areas and radar webs on POLYGON — so they stay vector on a report too.
One fix worth knowing: SHOW takes its color from the current target's font, not from SETPENCOLOR, so v1 silently ignored TextColor. v2 honours it via SETFONT(0,…); set ColorText = 0 to go back to the old behaviour.
Nuevo en v2.0 — trece tipos de gráfico. Una sola propiedad, ChartType, cambia entre Chart:Column, Chart:Bar, Chart:StackedCol, Chart:StackedBar, Chart:Stacked100, Chart:Line, Chart:Area, Chart:StackedArea, Chart:Scatter, Chart:Pie, Chart:Pie3D, Chart:Donut y Chart:Radar. Hasta 8 series (AddSeries + AddCat), leyenda, marcadores, líneas suavizadas (Catmull-Rom), etiquetas en porcentaje y una escala que hace caer el cero en una línea de rejilla. Todo lo de abajo sigue valiendo — la API de v1 (AddBar, ClearBars, SetRange, Draw, Paint) no cambió, y Chart:Column es el valor por defecto, así que el código de v1 dibuja igual que antes.
Pastel, pastel 3D y dona se apoyan en la sentencia PIE de Clarion, y las áreas y la telaraña del radar en POLYGON — así que también siguen siendo vectoriales en un informe.
Un arreglo que conviene saber: SHOW toma el color de la fuente del destino actual, no de SETPENCOLOR, así que v1 ignoraba TextColor sin avisar. v2 lo respeta con SETFONT(0,…); pon ColorText = 0 para volver al comportamiento anterior.

GraficaBarraClass is a single, self-contained ANSI Clarion class that draws thirteen kinds of chart using only the native graphics primitives — BOX, LINE, POLYGON, ELLIPSE, PIE and SHOW. It runs the same on a window (drawing into an IMAGE control) and on a report (drawing straight into the printed band). On a report the output is vector, never a bitmap, so PDF exports stay tiny and print sharp at any resolution — and that holds for every type, because pie and donut ride Clarion's own PIE statement and areas and radar webs ride POLYGON, both of which are valid on a REPORT.

GraficaBarraClass es una única clase ANSI de Clarion, autónoma, que dibuja trece tipos de gráfico usando solo las primitivas gráficas nativas — BOX, LINE, POLYGON, ELLIPSE, PIE y SHOW. Funciona igual en una ventana (dibujando en un control IMAGE) y en un informe (dibujando directamente en la banda impresa). En un informe la salida es vectorial, nunca un mapa de bits, por lo que los PDF quedan diminutos y se imprimen nítidos a cualquier resolución — y eso vale para todos los tipos, porque el pastel y la dona se apoyan en la sentencia PIE de Clarion y las áreas y la telaraña del radar en POLYGON, y ambas son válidas en un REPORT.

You can use it two ways: through the graficaBarra template (which wires everything for you — see the template docs), or directly from code as shown here. Either way the object is plain procedure data and every property/method below is available.

Puede usarla de dos maneras: mediante la plantilla graficaBarra (que conecta todo por usted — vea la documentación de la plantilla), o directamente desde código como se muestra aquí. En ambos casos el objeto es simplemente un dato del procedimiento y cada propiedad/método de abajo está disponible.

How the class worksCómo funciona la clase

The design is deliberately small. You feed it bars (a label, a value, and an optional color) and set a few look properties; then a single method, Paint, does all the drawing at the current graphics target. Everything is stored in the object, so it can redraw itself at any time (a window resize, a new report band) without you re-supplying the data.

El diseño es deliberadamente pequeño. Usted le proporciona barras (una etiqueta, un valor y un color opcional) y ajusta algunas propiedades de apariencia; luego un único método, Paint, hace todo el dibujo en el destino gráfico actual. Todo se guarda en el objeto, de modo que puede redibujarse en cualquier momento (al redimensionar una ventana, en una nueva banda del informe) sin que usted vuelva a suministrar los datos.

The drawing pipelineEl flujo de dibujo

  1. Measure. GETPOSITION reads the target control's rectangle (x, y, width, height).
  2. Medir. GETPOSITION lee el rectángulo del control destino (x, y, ancho, alto).
  3. Reserve margins for the title, the value labels above the bars, the scale numbers on the left, and the bar labels below — what's left is the plot rectangle.
  4. Reservar márgenes para el título, los valores sobre las barras, los números de escala a la izquierda y las etiquetas debajo — lo que queda es el rectángulo de trazado.
  5. Compute the value axis (see below) to get the low/high range mapped onto the plot height.
  6. Calcular el eje de valores (ver abajo) para obtener el rango bajo/alto mapeado sobre la altura del trazado.
  7. Draw gridlines + scale numbers, then one filled BOX per bar, the value/label text with SHOW, and finally the axis + zero baseline with LINE.
  8. Dibujar las líneas de cuadrícula + números de escala, luego un BOX relleno por barra, el texto de valor/etiqueta con SHOW, y por último el eje + línea base cero con LINE.

Because bars are drawn as vector BOX records and text as SHOW, the report engine carries them into the PDF as vectors — that is the whole reason to prefer this over drawing a chart into an image.

Como las barras se dibujan como registros vectoriales BOX y el texto como SHOW, el motor de informes los lleva al PDF como vectores — esa es toda la razón para preferir esto en lugar de dibujar un gráfico dentro de una imagen.

Scale & coordinatesEscala y coordenadas

Automatic "nice" scaleEscala "redonda" automática

With AutoScale = 1 (the default) the class scans your bar values and rounds the maximum up to the nearest 1, 2 or 5 × 10k — so 42 → 50, 71 → 100, 640 → 1000. If any value is negative, the minimum is rounded the same way in the other direction and the bars hang below a zero baseline. Call SetRange(min, max) to fix the scale yourself (this turns AutoScale off).

Con AutoScale = 1 (por defecto) la clase examina los valores de las barras y redondea el máximo hacia arriba al 1, 2 o 5 × 10k más cercano — así 42 → 50, 71 → 100, 640 → 1000. Si algún valor es negativo, el mínimo se redondea igual en la otra dirección y las barras cuelgan por debajo de una línea base cero. Llame a SetRange(min, max) para fijar la escala usted mismo (esto desactiva AutoScale).

Value → pixel mappingMapeo valor → píxel

A value v maps to a y-coordinate inside the plot rectangle of height ph (top py) as:

Un valor v se mapea a una coordenada y dentro del rectángulo de trazado de altura ph (borde superior py) como:

y = py + ph - INT(ph * (v - lo) / (hi - lo))

The zero baseline sits where v = 0 maps (at the bottom when all values are positive). Each bar is a BOX from the baseline to its value. Screen Y grows downward, which is why the formula subtracts from the bottom.

La línea base cero está donde se mapea v = 0 (en el fondo cuando todos los valores son positivos). Cada barra es un BOX desde la línea base hasta su valor. La Y de pantalla crece hacia abajo, por eso la fórmula resta desde el fondo.

Same code, both targets All coordinates come from GETPOSITION of the target control, so the identical Paint serves a window (coordinates in dialog units) and a report band (coordinates in 1/1000 inch). Only the text cell size differs — see below.
Mismo código, ambos destinos Todas las coordenadas provienen de GETPOSITION del control destino, así que el mismo Paint sirve para una ventana (coordenadas en unidades de diálogo) y para una banda de informe (coordenadas en 1/1000 de pulgada). Solo cambia el tamaño de celda de texto — vea abajo.

Window vs. report — the pWindowMode flagVentana vs. informe — el parámetro pWindowMode

Ventana. Hace SETTARGET(win, ?img), luego Paint(?img, 1). Así que en un informe siempre hace el SETTARGET usted mismo alrededor de la llamada a Paint, y usa cualquier control de banda (un IMAGE vacío o un BOX) puramente como marcador de posición — el gráfico se dibuja sobre ese rectángulo, y usted oculta el marcador para que nunca se imprima solo.

Text metricsMétricas de texto

The class centers labels and right-aligns scale numbers by estimating a character cell size, because there is no portable font-measuring call that works identically on a window DC and a report band. The defaults assume roughly a 10-point font:

La clase centra las etiquetas y alinea a la derecha los números de escala estimando un tamaño de celda de carácter, porque no existe una llamada portable de medición de fuente que funcione idénticamente en un DC de ventana y en una banda de informe. Los valores por defecto suponen aproximadamente una fuente de 10 puntos:

Example — a chart on a windowEjemplo — un gráfico en una ventana

Put an IMAGE control (?Graph) on the window as the canvas. Declare the object, load bars once, and redraw whenever the window opens or resizes.

Coloque un control IMAGE (?Graph) en la ventana como lienzo. Declare el objeto, cargue las barras una vez, y redibuje cuando la ventana se abra o se redimensione.

! ---- global (once) ----
  INCLUDE('GraficaBarraClass.INC'),ONCE

! ---- procedure data ----
Ventas   GraficaBarraClass

  ! ---- inside the window's ACCEPT loop ----
  CASE EVENT()
  OF EVENT:OpenWindow
    Ventas.Title = 'Ventas por mes'
    Ventas.AddBar('Ene', 42)              ! auto palette color
    Ventas.AddBar('Feb', 58)
    Ventas.AddBar('Mar', 35, 04657C0h)    ! explicit color (terracotta)
    Ventas.AddBar('Abr', 71)
    Ventas.Draw(Window, ?Graph)          ! draw it
  OF EVENT:Sized
    Ventas.Draw(Window, ?Graph)          ! repaint at the new size
  END
With the template The graficaBarra window extension writes exactly this for you — including a DO Refresh:Ventas routine — from the prompts. Use the template unless you need full manual control.
Con la plantilla La extensión de ventana graficaBarra escribe exactamente esto por usted — incluida una rutina DO Refresh:Ventas — a partir de las opciones. Use la plantilla salvo que necesite control manual total.

Example — a chart on a report (small PDF)Ejemplo — un gráfico en un informe (PDF pequeño)

Put a placeholder in the detail band — an empty IMAGE named ?GraphPlace, sized where the graph should print. In the Before Printing Detail embed, load the bars, target the report, paint, then hide the placeholder so only the vector graph prints.

Coloque un marcador en la banda de detalle — un IMAGE vacío llamado ?GraphPlace, del tamaño donde debe imprimirse el gráfico. En el embed Antes de imprimir el detalle, cargue las barras, seleccione el informe, dibuje, y luego oculte el marcador para que solo se imprima el gráfico vectorial.

! ---- procedure data ----
Grafico  GraficaBarraClass

  ! ---- Before Printing Detail Section embed ----
  Grafico.ClearBars()
  Grafico.Title = 'Resumen trimestral'
  Grafico.AddBar('Q1', Reg:Q1)          ! values from the record
  Grafico.AddBar('Q2', Reg:Q2)
  Grafico.AddBar('Q3', Reg:Q3)
  Grafico.AddBar('Q4', Reg:Q4)

  SETTARGET(Report, ?TheDetailBand)      ! aim at the band that HOLDS the placeholder
  Grafico.Paint(?GraphPlace)             ! vector primitives into that band
  ?GraphPlace{PROP:Hide} = 1          ! placeholder never prints itself
  SETTARGET()
Aim at the band, not just the report SETTARGET(Report) on its own sends every primitive to whichever band is being composed. With one chart you never notice; with two, both land in the same band on top of each other. Pass the band's field equate as the second argument — the band needs a USE(?SomeName) in the report formatter — and each chart goes where it belongs, including a chart in a group header or footer. The template works this out for you from the report structure. Drawing into a band before it prints is fine, and a repeating band does not accumulate the previous record's drawing.
Apunte a la banda, no solo al informe SETTARGET(Report) por sí solo envía todas las primitivas a la banda que se esté componiendo. Con un gráfico no se nota; con dos, ambos caen en la misma banda uno encima del otro. Pase el field equate de la banda como segundo argumento — la banda necesita un USE(?Nombre) en el formateador del informe — y cada gráfico va donde le toca, incluido uno en un encabezado o pie de grupo. La plantilla lo deduce sola de la estructura del informe. Dibujar en una banda antes de que se imprima no es problema, y una banda que se repite no acumula el dibujo del registro anterior.
Why it stays small Nothing here rasterizes. Each bar is a BOX record and each label a SHOW, so the PDF generator emits vector drawing operators — kilobytes, not a full-page bitmap, and crisp at any zoom.
Por qué queda pequeño Aquí nada se rasteriza. Cada barra es un registro BOX y cada etiqueta un SHOW, así que el generador de PDF emite operadores de dibujo vectorial — kilobytes, no un mapa de bits de página completa, y nítido a cualquier zoom.

Example — building bars from a data fileEjemplo — construir barras desde un archivo de datos

The bars don't have to be hard-coded. Loop a file or queue and call AddBar per row — clear first so a refresh doesn't stack duplicates.

Las barras no tienen que estar fijas en el código. Recorra un archivo o una cola y llame a AddBar por fila — limpie primero para que un refresco no acumule duplicados.

LoadGraph  ROUTINE
  Grafico.ClearBars()
  Grafico.Title = 'Ventas por vendedor'
  SET(Ven:ByName)
  LOOP
    IF ACCESS:Ventas.Next() THEN BREAK.
    Grafico.AddBar(Ven:Nombre, Ven:Total)   ! label + value from each record
  END
  Grafico.Draw(Window, ?Graph)              ! window: redraw now

For a fixed scale across refreshes (so bars are comparable run to run) add Grafico.SetRange(0, 5000) before Draw.

Para una escala fija entre refrescos (de modo que las barras sean comparables entre ejecuciones) agregue Grafico.SetRange(0, 5000) antes de Draw.

Using the class without the templateUsar la clase sin la plantilla

The class is independent of the template — you can drop it into any hand-coded Clarion program. The minimum is: INCLUDE the header, declare an instance, add bars, and draw. The constructor sets sensible defaults, so you only touch what you want to change.

La clase es independiente de la plantilla — puede incorporarla en cualquier programa Clarion escrito a mano. Lo mínimo es: hacer INCLUDE del encabezado, declarar una instancia, agregar barras y dibujar. El constructor establece valores por defecto razonables, así que solo toca lo que quiera cambiar.

  PROGRAM
  INCLUDE('GraficaBarraClass.INC'),ONCE
  MAP
  END

G   GraficaBarraClass
Win WINDOW('Demo'),AT(,,320,220),SYSTEM,GRAY
      IMAGE,AT(8,8,304,204),USE(?Graph)
    END
  CODE
  OPEN(Win)
  G.Demo()                       ! six sample bars
  G.Title = 'Prueba'
  G.Draw(Win, ?Graph)
  ACCEPT
    CASE EVENT()
    OF EVENT:Sized ; G.Draw(Win, ?Graph)
    END
  END
  CLOSE(Win)

No olvide los archivos Copie GraficaBarraClass.inc y .clw (ANSI) a la ruta de redirección o la compilación fallará con "archivo no encontrado". El atributo LINK compila el .clw automáticamente — sin paso de proyecto.
