myWordDoc - class reference

Every public property and method of WordDocClass and the six RTF tool classes, in the order the .inc files declare them, each with what it does and a line of Clarion that uses it. The guide is in myWordDoc-template.html.

Todas las propiedades y métodos públicos de WordDocClass y de las seis clases RTF, en el orden en que los declaran los .inc, cada uno con lo que hace y una línea de Clarion que lo usa. La guía está en myWordDoc-template.html.

ConventionsConvenciones #

The examples assume these declarations:

  INCLUDE('WordDocClass.INC'),ONCE
  INCLUDE('WordDocTools.INC'),ONCE
Doc1     WordDocClass            ! an editor on a window (or a hidden document)
Search   RtfSearchClass
Font     RtfFontClass
Text     RtfTextClass
Html     RtfHtmlClass
Md       RtfMarkdownClass
Merge    RtfMergeClass
  • Positions are 0-based character positions; a paragraph break counts as one.
  • Sizes in twips are 1/1440 inch: 720 = half an inch, 1440 = an inch.
  • Colours are Clarion colours (COLOR:Red, 0F0FFFFh); COLOR:None means automatic.
  • Methods marked PROC can be called as a statement, ignoring the result.

Los ejemplos suponen estas declaraciones:

  INCLUDE('WordDocClass.INC'),ONCE
  INCLUDE('WordDocTools.INC'),ONCE
Doc1     WordDocClass            ! un editor en una ventana (o un documento oculto)
Search   RtfSearchClass
Font     RtfFontClass
Text     RtfTextClass
Html     RtfHtmlClass
Md       RtfMarkdownClass
Merge    RtfMergeClass
  • Las posiciones son posiciones de carácter desde 0; un salto de párrafo cuenta como uno.
  • Los tamaños en twips son 1/1440 de pulgada: 720 = media pulgada, 1440 = una pulgada.
  • Los colores son colores de Clarion (COLOR:Red, 0F0FFFFh); COLOR:None significa automático.
  • Los métodos con PROC se pueden llamar como sentencia, ignorando el resultado.
